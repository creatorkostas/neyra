Room to grow.

Neyra is currently a useful speech-to-text app in an early state. The default Needle Whistle model is small and uses very little RAM. Its results are okay, rather than exceptional.

Speech recognition runs locally on your PC, and Voz moves its encoder to the GPU when the platform provides one. Optional assistant features use the text and screen snapshots you ask Neyra to share. Voice shortcuts work best on Windows and X11; native Wayland has restrictions.

A few things to know.

Does Neyra need an internet connection?

Local Whistle dictation can run offline once its model is available. Voz downloads about 1.2 GB of model files on first use, and meeting models download the same way. Optional assistant features need whatever connection their provider requires, and ChatGPT also needs an eligible account.

Do I need an OpenAI API key?

ChatGPT connects with Continue with ChatGPT, so no API key is stored. A local model server, OpenCode API, or OpenCode CLI uses its own endpoint and credentials, and running without an assistant still leaves local tool commands working. Screen questions currently require ChatGPT. ChatGPT account permissions, model availability, and plan usage limits still apply.

Can Neyra notify me when it is closed?

Keep Neyra running in the tray for scheduled reminder notifications. Overdue reminders appear when you reopen it. Closing the app completely stops its scheduler.

How do I install it on a Mac?

Download the Apple silicon ZIP, unzip it, and move Neyra.app to Applications. The app is unsigned, so macOS may ask you to approve it in System Settings → Privacy & Security. Allow microphone access and Accessibility access for voice shortcuts when prompted. Intel Macs are not supported by this download.

How do I install it on Arch Linux?

The repository includes tooling to prepare a neyra-bin AUR package. A generated package recipe is not an AUR publication. Check the AUR guide for the current setup and submission steps.

Where can I report a problem?

Open an issue on GitHub. Include your operating system, the engine you used, and the error text. Leave private transcripts and account credentials out of reports.
